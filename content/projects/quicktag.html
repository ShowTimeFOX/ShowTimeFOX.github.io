QuickTag LazyMod Overview

QuickTag LazyMod is a Manifest V3 browser extension for Chrome and Firefox designed to streamline image tagging using a floating interface. It supports editable tag packs, site-specific profiles, interface customization, and optional AI image analysis through a local ComfyUI installation.

Interface & Screenshots

Architecture & Key Features

  • Shadow DOM Isolation: The content script injects the interface inside a Shadow DOM to minimize style conflicts with host pages.
  • Per-Origin Settings: Docking mode, dock edge, panel visibility, and floating positions are saved separately for each page origin.
  • Global Visibility Toggle: A toolbar popup toggle immediately hides or shows QuickTag across all open pages without requiring page reloads.
  • Configurable Storage: Settings, site profiles, palettes, and the AI blacklist are stored locally using chrome.storage.local .

ComfyUI & AI Integration

Optional image analysis connects to a local ComfyUI server running at http://127.0.0.1:8188 with the WD14Tagger|pysssss custom node. The extension uploads the image via /upload/image , submits a prompt workflow, and retrieves tags by monitoring queue and history endpoints.

Core Logic Snippet 

async function analyzeImageWithComfy(imageBlob) {
  const formData = new FormData();
  formData.append('image', imageBlob);

  const response = await fetch('http://127.0.0.1:8188/upload/image', {
    method: 'POST',
    body: formData
  });
  
  if (!response.ok) throw new Error('Image upload failed');
  return await response.json();
}
