QuickTag LazyMod Overview

Manifest V3 browser extension for Chrome and Firefox designed to streamline image tagging via a floating, highly customizable interface. QuickTag LazyMod simplifies image tagging workflows by offering editable tag packs, site-specific profiles, and optional AI-powered image analysis integrated with a local ComfyUI instance.

Interface & Screenshots

Architecture & Core Engineering

  • Shadow DOM Isolation: Injects the entire UI into a Shadow DOM to completely eliminate CSS style leaks and conflicts with host websites.
  • Per-Origin State Persistence: Remembers UI docking positions, side-panel states, and floating window coordinates individually for every site origin.
  • Global Visibility Toggle: Instant toolbar popup switch to show or hide the overlay across all active tabs without reloading pages.
  • Configurable Local Storage: Uses chrome.storage.local to securely persist profiles, tag palettes, custom themes, and AI blacklists.

Key Features & User Experience

Tagging Workflow & Palettes

  • Zero-Setup Readiness: Ships with built-in preset palettes so you can start tagging immediately after installation.
  • Flexible Palette Management: Import, export, edit, or delete custom tag packs. Easily share your setups across multiple devices or with friends.
  • Smart Hierarchy & Flat View: Organizes tags into main categories and subcategories. Toggle "Flat View" to collapse all subcategories into a single streamlined view instantly.
  • Batch Tag Toggle: The "Add tags" master button acts as a quick switch to apply or clear all currently visible tags at once.
  • Type-to-Search: Blazing-fast global tag search—triggerable anywhere on the page without needing to focus on a specific input field.

Local AI Assistance (ComfyUI)

  • One-Click AI Analysis: Integrates seamlessly with a local ComfyUI server http://127.0.0.1:8188 powered by the WD14Tagger|pysssss node.
  • Smart Filtering & Thresholds: Set custom tag confidence thresholds (default: 0.35) and maintain a custom AI Tag Blacklist to automatically ignore unwanted suggestions.
  • Seamless API Pipeline: Handles automated image uploads via /upload/image, triggers execution workflows, and streams back tags by polling the queue and history API endpoints.

Customization & Window Management

  • Docking & Floating Modes: Free-float the window anywhere or dock it to any screen edge (Top, Bottom, Left, Right).
  • Ghost Mode: Toggle instant window transparency via a customizable hotkey or top-bar icon to inspect the underlying webpage without hiding your panel. Features an optional "Hold-to-view" mode.
  • Visual Themes & Scaling: Includes 6 built-in color themes, an ambient Custom Color Picker, and a window scale slider.

Built-in JSON Editor

  • EasyJSON Mode: Edit tag palettes visually without touching raw JSON syntax or worrying about missing commas.
  • Power-User Tooling: Word-wrap support, instant JSON formatting, standard keyboard shortcuts, and live-reloading—changes update in the main interface immediately upon saving.
