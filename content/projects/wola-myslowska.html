GBP Wola Mysłowska — Public Library CMS

Custom Content Management System (CMS) built from scratch for the Public Library in Wola Mysłowska. The system was engineered to provide library staff with a streamlined, intuitive dashboard, eliminating complex overhead in favor of a clean, single-screen management workflow. The administrative panel controls the core elements of the institution's public website, including the homepage hero carousel, news posts, photo galleries, and reader contact submissions.

Interface & Screenshots

Architecture & Core Stack

  • Framework & Tech Stack: Built with Laravel, Bootstrap, and a relational database for fast, reliable content management.
  • Session Security & Auth: Session-based authentication featuring an active idle timeout countdown timer (e.g., Session expires in: 14:31 ) and secure logout workflow.
  • Streamlined Admin Interface: Single-screen management layout designed for non-technical library staff to minimize administrative friction.

Core Modules & Features

Main Dashboard

  • Central Command Hub: Intuitive card-based layout providing instant access to primary actions: adding slides, publishing posts, managing photo galleries, and reviewing incoming reader submissions.

Slide Manager (Homepage Carousel)

  • Visual Presentation Control: Dedicated module to add, edit, and remove promotional slides displayed on the website's main hero carousel.
  • Ordered Display: Customizable display sequence numbers, custom titles, descriptions, and high-resolution image asset management.

Publishing System (Posts & News)

  • Content Categorization: Categorized entry publishing supporting distinct types such as News ( Aktualności ) and Projects ( Projekty ).
  • Rich WYSIWYG Editor: Advanced text editing suite equipped with heading formatting, lists, quotes, tables, image embeds, and media attachments.
  • Visibility Toggles: Quick controls for flagging posts as pinned (" Ważny ") and toggling public visibility status.

Photo Gallery & Albums

  • Structured Media Storage: Organizes media libraries into thematic photo albums (e.g., Book Signing events).
  • Asset Operations: Seamless uploading of new photography, metadata/caption editing, and quick removal via a clean grid interface.

User Inquiries & Administration

  • Direct Communication Inbox: Centralized inbox for reviewing messages and inquiries submitted through public website contact forms.
  • Access Management: Sub-module for provisioning administrator accounts accompanied by a built-in technical support section for maintenance.
